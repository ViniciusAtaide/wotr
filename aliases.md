# Name Variants & Known Typos

The guide mixes British and US spellings and contains a few typos. Grep this table before concluding a name is missing. All rows verified against the repo (June 2026).

| Guide spelling | Also try | Where |
| :--- | :--- | :--- |
| armour / unarmoured / armoured | armor / unarmored / armored | British in prose throughout (~350 hits) and `feats/armour-and-shield-feats.md`; US in proper names (Mage Armor, Armor Focus, Archmage Armor) and `items/armor-shields.md` |
| manoeuvre | maneuver | both forms throughout (77 vs 32 hits); file is `feats/combat-manoeuvres.md`, but "combat maneuver(s)" appears in classes/, feats/, mythic/ |
| defence / offence | defense / offense | both occur; prose is often British (incl. "Draconic Defences" AND "Draconic Defenses" in `classes/fighter.md`), named feats are US ("Shatter Defenses") |
| Neutralise Poison | Neutralize Poison | British in `spells/bard/bard-l4.md`, `spells/alchemist/alchemist-l4.md`, `spells/druid/druid-l3.md`, `mythic/aeon.md`, `mythic/angel.md`; US in cleric/druid-source lists and class pages |
| Swatooth Saber (typo) | Sawtooth Saber | typo at `feats/weapon-feats.md:27` (left as-is in source); correct "Sawtooth Saber" in `items/weapons.md`, `chargen/domains.md`, `classes/warpriest.md` |
| Sawtooth Saber | Sawtooth Sabre | guide consistently uses "Saber"; in-game/Pathfinder canonical spelling is "Sabre" (lowercase "sabres" also appears in `classes/warpriest.md`) |
| Dwarven Urgosh | Dwarven Urgrosh | "Urgosh" in `items/weapons.md:24,89`; "Urgrosh" in `items/weapons.md:463`, `classes/fighter.md:92`, `feats/weapon-feats.md:17`, `chargen/races.md` — same weapon |
| Aldori Duelling Mastery | Aldori Dueling Mastery | "Duelling" in `building/prereqs.md`; feat defined as "Aldori Dueling Mastery" in `feats/weapon-feats.md:66`; the weapon is always "Dueling Sword" |
| Favoured Enemy / favoured | Favored Enemy / favored | both spellings, even within `classes/ranger.md` (table US, prose British) |
| Maximise Spell / maximised | Maximize Spell / maximized | feat defined as "Maximise Spell" in `feats/magic-feats.md`; "Maximize Spell" in `classes/magus.md`; both participles in prose |
| specialisation / specialises | specialization | named feats always US ("Weapon Specialization", "Spell Specialization"); British only in prose (`classes/wizard.md`, `feats/magic-feats.md`, school specialisation) |
| demoralise | demoralize | mostly British (classes/, feats/, items/, mythic/trickster.md); US in `classes/prestige-classes.md`, `feats/unarmed-combat-feats.md` |
| paralysed / paralysing | paralyzed | British dominant (~29 files); US in `classes/paladin.md` and several witch/cleric spell files |
| Fervour | Fervor | Warpriest class feature is "Fervor"; one "Fervour" at `classes/warpriest.md:327` (Smite cost note) |
| stabilises | stabilize | British only (`classes/shaman.md`); no US occurrence |
| memorise / memorised | memorize | British only (witch/wizard spell-preparation prose); no US occurrence |
| penalised | penalized | British only; no US occurrence |
| recognises / mesmerised / minimise / optimise / summarised / practised / synergises / italicised | -ize / -iced forms | scattered British prose; US forms absent — search with `is(e\|ed\|es\|ing)` if a plain grep misses |
| favour / flavour / honour / behaviour / coloured | favor / flavor / honor / behavior / colored | low-frequency British prose; US "honor"/"fervor" also occur in items/ |

Not variants (checked): "Gray Garrison" (location) vs "Greybor" (companion) are different names, both correct; "Color Spray" and "Mage Armor" appear in US spelling only.
